# 정렬 옵션

## Column
하위 요소를 가로로 정렬할 방법:

- **Start**
- **CenterHorizontally**
- **End**

## Row
세로 정렬을 설정할 방법:

- **Top**
- **CenterVertically**
- **Bottom**

## Box
가로 및 세로 정렬을 결합하여 사용할 수 있는 방법:

- **TopStart**
- **TopCenter**
- **TopEnd**
- **CenterStart**
- **Center**
- **CenterEnd**
- **BottomStart**
- **BottomCenter**
- **BottomEnd**
